# AI 生成约束模板（图片 / 音频）

原则：**模型只负责按方向执行，不负责发挥创意**。所有自由发挥的口子都要在 prompt 里堵死。

## 1. 音色克隆 / 口播（audio_to_audio_plus）

### 参考音
- 以 `assets/template-audio/audio-ref.mp3` 作为唯一音色底样（不要用 3 秒的 `intro-voiceover.mp3`）；若宿主工具限制参考长度，可从该文件裁取前约 15 秒。
- 参考音必须无 BGM、无混响、单人干声。

### Prompt 固定结构
```
参考音频是一位港风低沉男声的真人朗读。请用和参考音频一致的音色、语速和语气，
以克制、平静的故事旁白感朗读下面这段文字。
要求：只念文案本身，不要念出书名号、标点或任何括号说明；
句子之间按语义自然停顿，不要拖长音，不要一个字重复发音；
全程语速平稳一致，不要忽快忽慢；语气克制、不煽情、不播音腔。

<这里空一行，下面只放纯文案，每行一句>
被讨厌的勇气
很多时候让你痛苦的
...
```

### 硬约束（必须逐条写进 prompt）
- 只念正文，不念《》、标点、括号；
- 一个字只发一次音，禁止重复；
- 语速全程平稳，不忽快忽慢；
- 克制旁白感，不播音腔、不刻意演口音；
- 指令段与正文用空行隔开。

### 长文案处理
- 长段一次性录总会随机糊一处；生成后用 Whisper **只取时间戳**定位糊点，用 ffmpeg 微切或短重录替换。
- Whisper 的同音别字（满意→买你、课题→客题）是正常现象，**只用于时间对齐，不作文字真源**；字幕真源永远是 approved 的 script.csv。

## 2. 氛围配图（image_gen）

### 方向约束（每图必带）
- **风景向为主**：不要清一色"人物居中大头特写"；
- **色调要有起伏**：同一支视频内几张图冷暖、明暗、场景要拉开（如冷青空巷 / 雨窗暖灯 / 雾中山林 / 暖金日出），不要全是深蓝冷调；
- **人物只作远景小点**：若出现人，必须是远景剪影，占画面极小比例，不是面部特写；
- 电影感、低饱和、胶片颗粒；竖版 3:4。

### 按情绪绑定画面（不要让模型自选题）
| 文案情绪 | 画面方向 |
|---|---|
| 委屈、讨好、内耗 | 空无一人的冷调街道 / 雨夜窗 / 孤立的背影 |
| 抽离、边界感 | 雾中长路 / 一扇半开的门 / 开阔留白 |
| 自由、释然 | 日出云海 / 山顶俯瞰 / 通向光的路（暖调） |

### 禁止
- 禁止人物面部居中大特写；
- 禁止多张图雷同（同色调同构图）；
- 禁止在画面里渲染大段文字；
- 禁止使用真实 IP / 在世艺术家风格名。
